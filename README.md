## 📌 Project Description
This project is a Rental Property Finder web application built using:
- HTML
- CSS
- JavaScript
- JSON Server (db.json)

## 🚀 Features
- View,Buy and Sell rental properties
- Admin panel to manage data
- Dynamic data loading using fetch API
- JSON Server as backend

## ⚙️ How to Run Project

1. Install JSON Server (if not installed):
   npm install -g json-server

2. Run JSON Server:
   json-server --watch db.json

3. Open project:
   Open index.html in browser

## 📁 Project Structure
- index.html → Main page  
- admin.html → Admin panel  
- style.css → Styling  
- app.js → Main logic  
- admin.js → Admin logic  
- db.json → Fake backend database  

## 📌 Note
Make sure JSON Server is running before using the app.
